📘 Pathsalaa - Learning Management System

📌 Description

Pathsalaa ek simple Java-based desktop application hai jo students aur teachers ke liye banaya gaya hai. Isme login system, resource sharing, doubt system aur quiz feature available hai.

---

🚀 Features

- 👨‍🏫 Teacher login & dashboard
- 👨‍🎓 Student login & dashboard
- 📂 File upload (Notes & Videos)
- 📖 Subject-wise resource access
- ❓ Doubt submission system
- 📝 Quiz feature
- 🔐 Login & registration system

---

🛠️ Technologies Used

- Java (Swing & AWT)
- File Handling (Text Files)

---

📂 Files Used

- "users.txt" → Login & registration data
- "resources.txt" → Uploaded files info
- "doubts.txt" → Student doubts

---

▶️ How to Run

1. Java install hona chahiye (JDK)
2. Code ko compile karo:
   javac Pathsalaa.java
3. Program run karo:
   java Pathsalaa

---

👤 User Roles

Teacher

- Files upload kar sakta hai
- Student doubts dekh sakta hai

Student

- Notes & videos access kar sakta hai
- Doubt submit kar sakta hai
- Quiz attempt kar sakta hai

---

📌 Note

- Ensure karo ki "users.txt", "resources.txt", aur "doubts.txt" same folder me ho
- File paths system ke according valid hone chahiye
